# Contributing to FolioFlux

Thanks for your interest in contributing. This guide applies to every repository in the [FolioFlux organization](https://github.com/folioflux) unless a repository has its own `CONTRIBUTING.md`.

## Before you start

- **Bugs:** search existing issues first, then open a new one using the bug report template.
- **Ideas and features:** open a feature request so we can discuss the approach before you write code.
- **Security issues:** do not open a public issue. Follow our [security policy](SECURITY.md).

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep changes focused: one fix or feature per pull request.
3. Add or update tests and docs where it makes sense.
4. Make sure the project builds and tests pass locally.
5. Write a clear description of what changed and why, and link the related issue.

We review pull requests as soon as we can and may ask for changes before merging.

## Data and privacy

FolioFlux works with financial data. Never include real bank exports, account numbers, receipts or other personal data in issues, pull requests, tests or fixtures. Use made-up sample data.

## Code of conduct

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
