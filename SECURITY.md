# Security policy

We take the security of FolioFlux and our users' financial data seriously. Thank you for helping us keep it safe.

## Reporting a vulnerability

**Please do not report security issues through public GitHub issues, discussions or pull requests.**

Report them privately in either of these ways:

- **GitHub private vulnerability reporting:** open the affected repository's **Security** tab and choose **Report a vulnerability**.
- **Email:** [security@folioflux.com](mailto:security@folioflux.com)

Please include:

- a description of the issue and its potential impact
- the affected product, URL, repository or version
- steps to reproduce, or a proof of concept
- any suggested fix, if you have one

We will acknowledge your report, keep you updated as we investigate, and let you know when it is fixed. Please give us reasonable time to address the issue before any public disclosure.

## Scope

This policy covers the repositories in the [FolioFlux GitHub organization](https://github.com/folioflux) and the FolioFlux service at [folioflux.com](https://folioflux.com). More about how we handle data: [folioflux.com/security](https://folioflux.com/security).

## Safe harbor

We will not pursue action against researchers who act in good faith, avoid privacy violations and service disruption, do not access or modify other users' data, and give us a chance to fix the issue before disclosing it.
