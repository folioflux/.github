# folioflux/.github

Organization-wide defaults for [FolioFlux](https://folioflux.com) on GitHub:

- [`profile/README.md`](profile/README.md): the public profile shown on [github.com/folioflux](https://github.com/folioflux)
- [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md): default community health files for every public repository without its own
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) and [`.github/pull_request_template.md`](.github/pull_request_template.md): default issue forms and pull request template

The profile banner is rendered from [`profile/assets/banner-source.html`](profile/assets/banner-source.html) with headless Chrome at 2x.
